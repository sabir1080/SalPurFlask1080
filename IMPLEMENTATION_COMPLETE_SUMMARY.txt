DATA FLOW VERIFICATION
================================================================================

USER INPUT
  ├─ Discount: 5, Type: %
  ├─ Tax: 10%
  └─ Triggers: applyDiscountTax() → updateTotalsDisplay()

FRONTEND CALCULATION
  ├─ Subtotal = sum(qty * price)
  ├─ Discount = gross × discount_value / 100
  ├─ Taxable = Subtotal - Discount
  ├─ Tax = Taxable × tax_percent / 100
  └─ Display updates real-time

CART OBJECT
  ├─ Each item gets: discount_type, discount_value, tax_percent
  └─ Values applied globally to all items

CHECKOUT PAYLOAD
  ├─ Sends cart items with all discount/tax fields
  └─ Backend receives complete data

BACKEND PROCESSING
  ├─ Calculates using existing calc_discount_tax()
  ├─ Stores in SaleItem table
  └─ Creates GL entries

DATABASE STORAGE
  ├─ SaleItem.discount_type
  ├─ SaleItem.discount_value
  ├─ SaleItem.discount_amount
  ├─ SaleItem.tax_percent
  ├─ SaleItem.tax_amount
  └─ SaleItem.amount (final)

INVOICE RENDERING
  ├─ Jinja template reads fields
  ├─ Shows Subtotal/Discount/Tax/Grand Total
  └─ Display conditional (only if > 0)
