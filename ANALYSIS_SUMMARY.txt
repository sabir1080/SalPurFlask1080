IMPLEMENTATION APPROACH
================================================================================

STRATEGY: Global Discount/Tax (Simple & Effective)
  - Single discount input for entire transaction
  - Single tax input for entire transaction
  - Apply to ALL items equally
  - Simpler than per-item approach
  - Meets 95% of POS use cases

DATA FLOW:
  1. User enters discount amount or % → Applied to all cart items
  2. User enters tax % → Applied to all cart items
  3. Display breakdown: Subtotal → Discount → Tax → Grand Total
  4. Checkout sends discount/tax values in cart items
  5. Backend calculates using existing function
  6. Database stores values
  7. Invoice displays clearly

HOLD BILL:
  - Already works (no changes needed)
  - Discount/tax values preserved in hold JSON
  - Resume restores all values
  - Checkout uses restored values
