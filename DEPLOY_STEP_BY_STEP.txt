================================================================================
STEP 1: APP.PY UPDATE (2 MINUTES)
================================================================================

1. app.py kholain (project root mein)

2. Sabse upar, import statements ke paas (around line 1-50):

   ADD THIS:
   --------
   from salpurflask.models.business_config import (
       BusinessCategory, ProductField, ProductCategoryData,
       CategoryMenuItem, CategoryReport, CategoryValidation,
       ConfigurationSnapshot
   )

3. Blueprint registrations ke paas (around line 80-100):

   ADD THIS:
   --------
   from salpurflask.routes.admin_config import config_bp
   app.register_blueprint(config_bp)

4. create_app() function ke andar, db.init_app(app) ke baad:

   ADD THIS:
   --------
   with app.app_context():
       db.create_all()
       from salpurflask.models.business_config import BusinessCategory
       if BusinessCategory.query.count() == 0:
           from seed_business_categories import seed_categories
           seed_categories()

5. SAVE krain!

================================================================================
PROBLEMS? SOLVE KAR DO
================================================================================

Problem 1: "Page not found" /admin/config par
Solution:
  - app.py mein config_bp import aur register ho gaya check karain
  - Server restart karain
  - Browser refresh karain (Ctrl+F5)

Problem 2: "No categories showing"
Solution:
  - seed script run ho gaya check karain
  - Database migration successful tha check karain (flask db upgrade)
  - Server restart karain

Problem 3: "Can't enable category"
Solution:
  - Logged in as admin ho check karain
  - Admin ko role='admin' ho check karain

Problem 4: "Product form fields show nahi ho rahen"
Solution:
  - Category enable ho check karain
  - Browser refresh karain (Ctrl+F5)
  - Console mein error check karain (F12)
